This website is run by Building Control. We want as many people as possible to be able to use it — whoever you are, and however you access the web. That means you should be able to change colours and contrast, zoom in without the text spilling off the screen, navigate by keyboard, and use a screen reader.

Compliance status

Fully compliant
This website is fully compliant with the Web Content Accessibility Guidelines (WCAG) 2.2 level AA.

We test the service regularly against these standards, both with automated tools and with people using assistive technology, and we fix issues as part of our normal release process.

Known issues

We're not aware of any accessibility issues that prevent you from using the service. The areas below are ones we're actively monitoring and improving:

  • Some older PDF guidance documents may not be fully tagged for screen readers. We're replacing these with accessible web pages.
  • On the application map, selecting a site by mouse is currently easier than by keyboard. A postcode and grid-reference alternative is always available.

If you find a problem that isn't listed here, please tell us — see reporting a problem below.

Reporting a problem

We're always looking to improve. If you find something that's hard to use, or you need help with anything on this site, get in touch and we'll do our best to put it right.

Emailaccessibility@buildingcontrol.gov.uk
Phone0800 000 0000 — Monday to Friday, 9am to 5pm

We aim to respond within 5 working days.

Requesting content in an alternative format

If you need information on this website in a different format — such as accessible PDF, large print, easy read, audio recording, or braille — let us know and we'll help.

When you contact us, please tell us:

  • The web address (URL) of the content you need
  • Your name and email address
  • The format you need — for example, large print or audio

We'll consider your request and get back to you within 10 working days.

Enforcement

If you contact us with a complaint and you're not happy with our response, you can contact the relevant accessibility monitoring body, who are responsible for enforcing the accessibility regulations.
